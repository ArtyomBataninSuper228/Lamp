Разработка программного обеспечения:
Для выполнения измерений было разработано ПО для микроконтроллера stm32f411 и для компьютера.
Микроконтроллер управляет реле, сохраняет выборки в буфер и отправляет их на компьютер по serial port.
ПО для него было сделано на языке c++. (Лежит в папке репозитория stm32_code)
По для пк выполняет следующие функции:(обозначить при помощи блока \{itemise}[label{---}]
 -Отображение графического интерфейса
 -Обмен командами управления с платой
 -Хранение данных, построение графиков
 -Анализ данных
ПО для пк состоит из следующих программ(папка python_code):(обозначить при помощи блока \{itemise}[label{---}]
 -pult - программа для управления установкой, сохранения файлов и изменения
 -grafic - программа для построения графиков и перевода значений из битов ацп в напряжение, которрое было на входе в ацп
 -noise_analyser - программа для анализа статистической неопределенности на основе измерений без лампочки. (оценки влияния тепловых шумов ацп, влиия помех, генерируемых реле при переключении, и  электромагнитных полей)
