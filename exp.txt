Разработка программного обеспечения:
Для выполнения измерений было разработано ПО для микроконтроллера stm32f411 и для компьютера.
Микроконтроллер управляет реле, сохраняет выборки в буфер и отправляет их на компьютер по serial port.
ПО для него было сделано на языке c++. (Лежит в папке репозитория stm32_code)
По для пк выполняет следующие функции:(обозначить при помощи блока \start{itemise}[label{---}]
 -Отображение графического интерфейса
 -Обмен командами управления с платой
 -Хранение данных, построение графиков
 -Анализ данных
ПО для пк состоит из следующих программ(папка python_code):(обозначить при помощи блока \{itemise}[label{---}]
 -pult - программа для управления установкой, сохранения файлов и изменения
 -grafic - программа для построения графиков и перевода значений из битов ацп в напряжение, которрое было на входе в ацп
 -noise_analyser - программа для анализа статистической неопределенности на основе измерений без лампочки. (оценки влияния тепловых шумов ацп, влиия помех, генерируемых реле при переключении, и  электромагнитных полей)

Проведение эксперимента:
Сначала мы провели измерения для лампы работающей в стандартном режиме. (рис какой то через autoref, cool_data.png сюда бы) Измерения проводились при выключенно свете вечером в тёмной коробке (файлы black box).
Для анализа фонового уровня освещения были сделаны измерения без ламп (black box noises) (добавь соответствующую картинку)
В первых измерениях производилась подстройка резистора R2 для того что бы напряжение на катоде фотодиода не выходило за пределы измерения ацп (3.3V).(добавь black_box 0/1 мелкими, главное что бы было видно клиппинг)
Для изучения перегорания лампы её колба была разбита и проведены измерения fire_1 fire2_2. измерения fire1 были неудачны - спираль неуспела догореть до конца измерений.
файл fire2_2 представляет больший интерес т.к именно в нём сохранены наиболее важные данные(Добавь файл fire2_2).
К сожалению в момент перегара нити скачка тока зафиксировано не было - ток просто перестал течь. Это обьясняется низким напряжением работы лампы - 12 вольт не могут создать достаточно дилнную дугу для того что бы сопротивление значительно упало.
Полученные нами экспериментальные данные не опровергают выдвинутую выше гипотезу, для её необходимо провести эксперимент с бОльшим (поставь ударение на О) напряжением.
